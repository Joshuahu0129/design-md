# Awesome DESIGN.md

将 DESIGN.md 复制到你的项目中，告诉你的 AI 智能体「帮我生成一个看起来像这样的页面」，即可生成与该设计语言在视觉上保持一致的高质量 UI。

基于真实的设计深度构建——包含经过分析的模式、设计令牌（tokens）和规则——用于生成高质量的 UI，而非表面化的产出。


## 什么是 DESIGN.md？

[DESIGN.md](https://stitch.withgoogle.com/docs/design-md/overview/) 是 Google Stitch 提出的一个新概念。它是一份纯文本的设计系统文档，AI 智能体可以读取它来生成风格一致的 UI。

它只是一个 markdown 文件。不需要 Figma 导出文件，不需要 JSON schema，也不需要特殊工具。把它放进项目根目录，任何 AI 编程智能体或 Google Stitch 都能立刻理解你的 UI 应该长什么样。Markdown 是大语言模型最擅长阅读的格式，因此不需要额外的解析或配置。

| 文件 | 谁来读取 | 定义了什么 |
|------|-------------|-----------------|
| `AGENTS.md` | 编程智能体 | 如何构建这个项目 |
| `DESIGN.md` | 设计智能体 | 项目应该呈现出怎样的外观和感觉 |

**本仓库提供了从真实网站中提取的、可直接使用的 DESIGN.md 文件。**

## 每份 DESIGN.md 包含哪些内容

每个文件都遵循 [Stitch DESIGN.md 规范](https://stitch.withgoogle.com/docs/design-md/specification/)，并加入了扩展章节：

| # | 章节 | 记录内容 |
|---|---------|-----------------|
| 1 | 视觉主题与氛围 | 情绪基调、密度、设计理念 |
| 2 | 色彩方案与角色 | 语义化名称 + 十六进制值 + 功能角色 |
| 3 | 排版规则 | 字体家族、完整的层级表 |
| 4 | 组件样式 | 按钮、卡片、输入框、导航及其各状态 |
| 5 | 布局原则 | 间距体系、网格、留白理念 |
| 6 | 深度与层次 | 阴影系统、表面层级 |
| 7 | 应做与不应做 | 设计守则与反模式 |
| 8 | 响应式行为 | 断点、触控目标尺寸、收起策略 |
| 9 | 智能体提示词指南 | 快速配色参考、可直接使用的提示词 |

每个站点都包含：

| 文件 | 用途 |
|------|---------|
| `DESIGN.md` | 设计系统本身（智能体读取的内容） |
| `preview.html` | 展示配色样例、字号层级、按钮、卡片的可视化目录 |
| `preview-dark.html` | 同样的目录，深色版本 |

### 使用方法


1. 将某个站点的 `DESIGN.md` 复制到你的项目根目录
2. 告诉你的 AI 智能体使用它。
